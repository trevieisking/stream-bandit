Recommended workflow

Prepare

Record the Master Plan, save project details, choose the project and load the complete source file.

Describe

Record what is broken, preserve working behaviour and build the repair packet.

Repair

Use Buddy Canvas, Workflow Hub, Patch Desk or Patch Lab for the fixed output.

Test

Run Preview + Test and save a Checkpoint before repository work.

Review

Use Repo Desk, CG Repair Lab and Code God to understand and verify the exact repository action.

Handoff

Use the protected GitHub Writer and Tracker for the existing non-main branch, draft pull request and exact-head checks.

Checklist

Finish at Master Plan Checklist and keep unresolved, missing or user-check evidence out of PASS.
