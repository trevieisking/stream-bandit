This page groups the optional Code Labs specialist tools used around repair work. Scan Labs can inspect an exact whole-repository snapshot before a file is selected, but it never advances, blocks or owns the numbered workflow.

Use order

  2. Return to the existing workflow.
  3. Load one exact source file.
  4. Prepare and review a full replacement.
  5. Use branch and pull request only.
